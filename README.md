# Edinburgh Festival Partnerships

A linear hackathon presentation: audience evidence → data-ranked partner map → example pilot costs.

The five evidence charts use selected, anonymous aggregates. Multi-event purchasing shows one sample only, capped at 10 events and 50 paid tickets per booker over the festival year. Six recommendations are chosen from complete schedules and verified venues, ranked by strict within-festival co-purchasing support, lift and paid demand, with distinct venue locations. Each candidate names a measured co-purchase pair, its overlap ratio and the interval before Tattoo. Selecting a map pin updates the recommendation and schedule; costs are only shown in the final stage. The cost stage explains the budget, net gain and extra-ticket measures and shows each preset’s campaign budget.

The static release contains only the interface and a small curated `demo-summary.json`. Original customer/order records, complete evidence/catalogue snapshots, the old performance map dataset and source maps are excluded. All analysis remains local. There is no full-data browser, manual calculator or mandatory download.

GitHub Pages deploys the allowlisted `site.zip` through GitHub Actions. Street tiles come from OpenStreetMap; an interactive coordinate map remains available if tiles cannot load.
